本文定义 V1.0（MVP）的业务目标、范围、功能、交互、兼容性、非功能与验收标准，作为设计、研发、测试的唯一需求基线。

本版本为 **V1.0 首版需求**。相对“仅网格/列表 + 点开预览”的传统整理思路，V1.0 **内置**短视频式全屏滑动浏览，作为核心体验，而非后续补丁。

| 能力 | 传统整理思路 | 本 V1.0 |
|------|--------------|---------|

| 手势 | 基础浏览手势 | 上滑/下滑切换、单击暂停、双击标记、长按倍速等 |

## 1. 项目背景与目标

### 1.1 背景

用户手机内有一个**总文件夹**，层级深、子文件夹多，内含**数千张图片**。现有文件管理器 / 相册类工具存在明显短板：

1. 必须逐层点进文件夹才能看到视频，效率极低；
2. 无法跨文件夹统一浏览、筛选、标记；
3. 浏览时只能一个个打开，无法像短视频一样连续滑动过图；
4. 批量剪切到新文件夹操作繁琐；
5. 视频格式多样，张分无法浏览或生成缩略图。

### 1.2 产品目标

做一款 **Android 本地图片整理工具**，实现：

| 目标 | 说明 |
|------|------|
| 指定总文件夹 | 递归扫描其下所有视频 |
| 扁平化浏览 | 不逐层点文件夹，直接看到全张图片 |
| 短视频式过图 | 全屏浏览，上下滑动切换，快速过图 |
| 边看边标记 | 滑动过程中一键标记、打星、加标签 |
| 一键剪切 | 批量移动到指定文件夹，脱离原层级 |
| 强兼容 | 常见容器/编码可识别、缩略图、浏览或兜底打开 |

### 1.3 成功标准（V1.0 北极星）

用户能在 **1 次扫描 + 1 次滑动过图 + 1 次批量剪切** 内，完成对“深层级大图库”中一批视频的归档整理，且过程无明显卡顿、无误删源文件。

## 2. 用户角色与典型场景

### 2.1 目标用户

手机里有一个深层级视频总文件夹、需要批量整理归档的个人用户（非专业剪辑师）。

### 2.2 典型场景（User Story）

**场景 A：首次扫描 + 全库过图**

1. 用户指定总文件夹 `/MyImages`；
2. APP 递归扫描出约 5000 张图片；
3. 用户进入滑动浏览，全屏浏览，上滑快速过图；
4. 想要的视频双击标记「保留」；不想要的点「待删除」；
5. 回到列表，筛选「保留」，一键剪切到 `/整理/精选`。

**场景 B：按路径批量处理**

1. 用户筛选路径包含 `2024/旅行`；
2. 进入滑动模式逐个查看并标记；
3. 批量剪切到目标归档目录。

**场景 C：只处理未整理**

1. 快捷筛选「未整理」；
2. 滑动过图补全标记；
3. 对「待删除」批量删除或剪切到回收区（若启用）。

### 2.3 关键用户任务

| 优先级 | 任务 | 期望耗时感 |
|--------|------|------------|
| P0 | 扫全库并看到全张图片 | 首次可后台完成，界面有进度 |
| P0 | 像刷短视频一样过图 | 切换 < 500ms |
| P0 | 边看边标 | 单次标记 ≤ 1 步 |
| P0 | 多选剪切归档 | ≤ 3 步完成选择目标并开始任务 |
| P1 | 按路径/条件缩小范围 | ≤ 2 步出结果 |

## 3. 范围定义

### 3.1 V1.0（MVP）包含

- 指定总文件夹（单根）；
- 递归扫描、扁平化索引；
- 扁平化网格/列表浏览；
- **短视频式全屏滑动浏览**；
- 相对路径展示与路径筛选；
- 按路径关键词、日期、时长、大小、格式、标记状态筛选；
- 标记：状态、标签、颜色、星级、备注；
- 批量选择 + 一键剪切到指定文件夹；
- 任务进度、失败重试、取消；
- 常见格式兼容与兜底浏览/打开。

### 3.2 V1.0 明确不做

| 不做项 | 说明 |
|--------|------|
| **缩略图 / 封面截帧 / 封面缓存** | **2026-09-28 确认取消**；列表用扩展名占位 |
| 云端同步 / 上传 / 社交分享（除系统分享面板） | 全张本地 |
| 视频剪辑、转码、压缩 | 后续可选 |
| 重复视频智能识别 | 二期 |
| 多根文件夹并行管理 | 二期；V1.0 仅单根，可更换 |
| 桌面端 | 不做 |
| AI 内容识别 | 三期 |

### 3.3 假设与约束（产品默认假设）

在「待确认问题」未回复前，V1.0 按下列默认推进，可通过附录变更：

| 项 | V1.0 默认 |
|----|-----------|
| 分发渠道 | 先侧载/自用友好；Google Play 上架按 SAF 优先方案预留 |
| 滑动方向 | **上下滑**切换视频（核心）；左右滑默认可配置为快进/快退 |

## 4. 核心用户流程

### 4.1 首次使用

```
请求权限 → 选择总文件夹 → 后台递归扫描
→ 建立扁平化索引（含相对路径）→ 缩略图懒生成/缓存
→ 进入图库（展示全张图片）
```

**关键体验：** 扫描可后台继续；列表可先出张分结果（流式入库更佳，V1.0 至少要有进度条 + 扫描完成后刷新）。

### 4.2 短视频式滑动浏览（核心）

```
列表/网格点击某视频
→ 进入滑动模式（当前筛选结果 = 浏览列表）
→ 全屏自动浏览
→ 上滑下一个 / 下滑上一个
→ 单击暂停；双击标记「保留」；底张按钮改状态/标签/星级等
→ 返回列表，标记已生效并同步 UI
```

### 4.3 快速筛选与标记

```
设筛选条件 → 列表实时刷新 → 点进滑动模式过图
→ 边看边标 →（可选）列表批量改标签/颜色/备注
```

### 4.4 一键剪切

```
多选（或从筛选结果全选）→「剪切到」→ 选目标文件夹
→ 选冲突策略 → 二次确认 → 任务队列执行
→ 进度反馈 → 成功更新索引与标记；失败可重试且不删源
```

## 5. 功能需求

> 验收写法：每条 FR 含「要求」与「验收标准」。未标注优先级者默认为 P0（MVP 必做）。

---

### FR-01 总文件夹设定（P0）

**要求**

1. 用户可指定一个根文件夹作为扫描范围；
2. 通过系统文件夹选择器（SAF）选择；
3. 记住上次选择；支持更换根文件夹；
4. 界面显示当前根文件夹可读路径。

**验收标准**

- 选定根文件夹后，APP **仅**扫描该文件夹及其子文件夹；
- 重启 APP 后仍恢复上次根文件夹（URI 权限仍有效时）；
- 更换根文件夹时提示将重建索引（可保留旧标记策略见 FR-08）。

---

### FR-02 递归扫描与扁平化索引（P0）

**要求**

1. 递归遍历根下所有层级；
2. 识别视频文件（按扩展名 + MIME，双保险）；
3. 为每个视频记录至少：绝对路径、相对路径、层级深度、文件名、大小、时长、分辨率、编码、容器、拍摄日期、修改日期、URI/MediaStoreId（可得则记）；
4. 建立扁平化索引（Room）；
5. 支持手动刷新；支持增量扫描（按修改时间/存在性 diff）；
6. 扫描后台执行，不阻塞主界面。

**验收标准**

- 约 5000 张图片：首次索引目标 **≤ 60s**（视存储介质浮动，需有进度与可取消）；
- 无文件变更时增量扫描目标 **≤ 5s**；
- 扫描中断后可继续或安全重扫，不产生重复脏数据。

---

### FR-03 扁平化浏览（P0）

**要求**

1. 默认直接展示全张图片，无需逐层进文件夹；
2. 网格视图 + 列表视图切换；
3. 网格：缩略图、时长、分辨率（可选）、标记状态；
4. 列表：文件名、相对路径、日期、大小、时长、格式；
5. 排序：日期、名称、大小、时长、分辨率、路径；
6. 快速滚动 + 缩略图懒加载。

**验收标准**

- 5000 条列表滚动目标流畅（见 NFR）；
- 无缩略图时显示占位，不阻塞滚动。

---

### FR-04 路径信息展示（P0）

**要求**

1. 每个视频显示相对根的相对路径，如 `2024/旅行/日本/day1.mp4`；
2. 过长路径中间省略，保留首尾；
3. 点击可查看完整路径；支持复制路径；
4. 支持按路径排序。

**验收标准**

- 相对路径正确反映相对当前根的层级；
- 完整路径弹层可复制成功。

---

### FR-05 路径筛选（P0）

**要求**

1. 路径关键词包含筛选；
2. 按子文件夹筛选（从已索引路径聚合）；
3. 按层级深度筛选（可选 P1）；
4. 排除路径关键词；
5. 可保存当前路径相关条件为「智能分类」。

**验收标准**

- 输入 `旅行` 仅显示相对路径含「旅行」的视频；
- 排除关键词生效；
- 智能分类保存后可一键恢复。

---

### FR-06 短视频式滑动浏览（P0 · 核心）

#### FR-06.1 进入方式

1. 在图库网格/列表点击任意视频进入；
2. **当前筛选 + 当前排序结果** 自动成为浏览列表；
3. 从点击项开始，可向前/向后滑动。

#### FR-06.2 浏览行为

1. 全屏沉浸式；状态栏/导航栏可配置隐藏；
2. 进入后自动浏览；
3. 上滑下一个，下滑上一个；切换后自动浏览；
4. 播完自动下一个（可配置：自动下一个 / 循环当前 / 停止）；
5. 后台浏览：V1.0 可做「可选开关」，默认关（P1）。

#### FR-06.3 手势

| 手势 | 默认行为 | 可配置 |
|------|----------|--------|
| 上滑 | 下一个 | 否（方向可对调） |
| 下滑 | 上一个 | 否（方向可对调） |
| 单击 | 暂停/浏览 | 否 |
| 双击 | 标记「保留」 | 是（可改其他状态） |
| 长按 | 2x 倍速，松开关闭 | 倍速值可配 |
| 左右滑 | 快进/快退 | 可改为禁用 |
| 双指缩放 | 画面比例（P1） | 可选 |

#### FR-06.4 浏览控制

- 底张进度条可拖动；当前时间/总时长；
- 倍速：0.5x / 1.0x / 1.5x / 2.0x；
- 静音；系统音量走系统手势即可；
- 字幕开关与选择（有则显示）；
- 音轨切换（有则显示）；
- 画面比例：适应 / 拉伸 / 裁剪；
- 旋转画面；锁定竖屏/横屏/自动。

#### FR-06.5 标记操作（滑动内）

底张固定操作区：

- 状态：未整理 / 保留 / 待定 / 待删除 / 已剪切；
- 标签：快速选已有标签；
- 星级：1–5；
- 颜色：红 / 黄 / 绿 / 蓝 / 紫；
- 备注：快速输入；
- 剪切到：选目标文件夹（单条）；
- 删除：二次确认；移入系统删除请求或直接删（按权限）；
- 分享：系统分享。

规则：

- 标记后 **默认不**自动下一个（可配置自动下一个）；
- 标记状态实时显示；
- 支持撤销上一次标记（内存级撤销栈即可，V1.0）。

#### FR-06.6 信息显示

- 顶：文件名、相对路径、序号/总数；
- 底：标记状态、标签、星级、颜色；
- 一键隐藏 UI，沉浸观看。

#### FR-06.7 预加载与性能

- 预加载当前前后各 N 个，N 可配 **1–3**，默认 1；
- 切换无明显黑屏/卡顿；
- 大文件：优先元数据 + 首帧/起始缓冲，不全量预缓冲；
- 及时释放远离当前页的浏览器实例。

#### FR-06.8 兼容性（浏览）

- 硬解优先 → 失败自动软解 → 再失败「用其他应用打开」；
- 不支持格式明确提示，**禁止闪退**。

#### FR-06.9 退出

- 返回键/手势退出回列表；
- 可选保存浏览进度；
- 退出时标记已持久化。

**验收标准（FR-06）**

1. 上滑/下滑切换流畅；
2. 5000 张列表内任意相邻切换，目标响应 **< 500ms**；
3. 双击标记后，返回列表可见状态已更新；
4. 硬解失败自动软解或友好降级，不闪退；
5. 预加载 1–3 时，滑动场景内存占用目标 **≤ 500MB**（中端机可测）。

### FR-07 筛选、搜索、排序（P0）

**筛选：** 路径关键词、子文件夹、日期范围、时长范围、大小范围、分辨率、扩展名、视频编码、标记状态、是否已剪切。

**搜索：** 文件名、路径、标签、备注。

**排序：** 日期、名称、大小、时长、分辨率、路径、随机。

**智能分类：** 保存当前筛选条件，可命名、编辑、删除。

**快捷入口（P0）：** 「只看未整理 / 未标记」。

**验收标准**

- 条件组合生效；清空后恢复全库；
- 智能分类重启后仍在。

---

### FR-08 标记系统（P0）

1. 预置状态：未整理、保留、待定、待删除、已剪切；
2. 自定义标签：增删改、配色；
3. 星级 1–5；颜色标记；文本备注；
4. 标记与视频逻辑关联：剪切移动后仍保留（按文件指纹：优先 URI/路径更新后重绑）；
5. 支持批量标记与取消。

**验收标准**

- 杀进程重启后标记仍在；
- 剪切成功后目标文件仍带原标记。

---

### FR-09 批量选择（P0）

1. 长按进入多选；
2. 点选、全选、反选；范围选择（P1）；
3. 按当前筛选结果全选；
4. 底张显示已选数量与操作栏。

---

### FR-10 一键剪切到指定文件夹（P0）

**UI 文案：**「剪切到」；**语义：** 移动（Move）。

**要求**

1. 目标：系统选择器 / 最近使用 / 预设 / 新建文件夹；
2. 剪切后文件脱离原层级，出现在目标目录；
3. 冲突策略：自动重命名 / 跳过 / 覆盖 / 每次询问；
4. 执行：同卷优先 rename；跨卷 copy → 校验 → 删源；
5. 更新 MediaStore、本地库、标记；
6. 任务：进度、暂停/继续（能做则做）、取消、失败重试；
7. 安全：二次确认；**失败不删源**。

**验收标准**

- 100 个视频批量剪切：成功文件在目标可播；源已删除（成功项）；标记保留；
- 任一项失败不影响已成功项的正确性，且失败项源仍在。

### FR-14 设置（P0）

| 分组 | 项 |

## 6. 视频兼容性需求（重点）

### 6.1 容器

MP4、M4V、MOV、MKV、WebM、AVI、WMV、FLV、TS、M2TS、MTS、3GP、MPG、MPEG、RMVB、RM、VOB、ASF。

> V1.0：**必保** MP4 / MKV / MOV / WebM / TS / AVI；其余「尽力 + 软解/外张打开」，不可闪退。

### 6.2 视频编码

H.264、H.265/HEVC、VP8、VP9、AV1、MPEG-4、MPEG-2、VC-1、WMV3、RealImage 等（设备与软解能力决定实际可播）。

### 6.3 音频编码

AAC、MP3、AC3、EAC3、FLAC、Opus、Vorbis、PCM、DTS、TrueHD 等。

### 6.4 字幕

- 外挂：SRT、ASS、SSA、VTT；
- 内嵌：MKV 等；
- 编码识别防乱码；开关与基础样式（大小/颜色 P1）。

### 6.5 浏览策略

1. **硬解优先：** Media3 ExoPlayer；
2. **软解兜底：** LibVLC（或 FFmpeg 方案，见技术选型）；
3. **外张打开：** 仍失败时 `ACTION_VIEW`。

### 6.6 缩略图

MediaMetadataRetriever → LibVLC/FFmpeg → 占位图；可指定时间点；磁盘缓存可清理。

### 6.7 元数据

时长、分辨率、帧率、码率、编码、旋转、拍摄/修改日期、音轨、字幕、HDR 信息（可得则展示）。

### 6.8 失败体验

文案明确：「当前设备不支持该格式」；提供「尝试软解」「用其他应用打开」；不闪退、不卡死。

## 7. 非功能需求

### 7.1 性能

| 指标 | 目标 |
|------|------|
| 5000 条列表滚动 | 目标 60fps（中端机可接受轻微掉帧） |
| 滑动切换响应 | < 500ms |
| 预加载内存 | ≤ 500MB（N=1–3） |
| 缩略图 | 懒加载 + 磁盘缓存 |
| 首次扫描 | 后台 + 进度 |
| 大文件剪切 | 进度可见，可后台继续（WorkManager） |

### 7.2 存储

- DB：Room；
- 缩略图磁盘缓存设上限；
- 任务日志可清理。

### 7.3 权限

| 系统版本 | 策略 |
|----------|------|
| Android 13+ | `READ_MEDIA_VIDEO`；按需请求 |
| Android 14+ | 注意张分授权（Selected Photos/Images）与 SAF 组合 |
| Android 10 及以下 | `READ_EXTERNAL_STORAGE` 等 |
| 写入目标 | SAF + 持久化 URI 权限 |
| 删除 | `MediaStore.createDeleteRequest` 或 SAF |
| 全盘管理 | **慎用** `MANAGE_EXTERNAL_STORAGE`；Play 上架需强理由 |

### 7.4 隐私与安全

- 本地处理，不上传视频；
- 剪切/删除二次确认；
- 失败不删源；
- 隐私说明写入设置页。

### 7.5 稳定性

- 崩溃率目标 < 0.5%；
- 剪切失败可重试；
- DB 异常可恢复（导出/重建索引）；
- 扫描中断可继续。

### 7.6 易用性

- 主路径操作 ≤ 3 步；
- 批量操作有明确反馈；
- 深色模式；
- 中文界面。

## 10. 技术选型建议

| 模块 | 建议 |
|------|------|
| 语言 | Kotlin |
| UI | Jetpack Compose |
| 浏览 | Media3 ExoPlayer + LibVLC 兜底 |
| 缩略图 | MediaMetadataRetriever + LibVLC/FFmpeg 兜底 |
| DB | Room |
| 列表 | Paging 3 |
| 后台 | WorkManager |
| 图片 | Coil |
| DI | Hilt |
| 异步 | Coroutines + Flow |
| 文件 | MediaStore + SAF + DocumentFile |
| 权限 | 按版本动态申请 |

**兼容性策略选择**

| 方案 | 优点 | 代价 |
|------|------|------|
| Media3 + LibVLC | 格式覆盖面大，落地快 | 包体积 +20–30MB 量级 |
| Media3 + FFmpeg 扩展 | 体积相对可控 | 编译复杂，老格式可能弱于 VLC |

**商店策略：** 优先 SAF + MediaStore；避免无必要的全盘文件权限。

## 11. 验收标准总表（发布门禁）

1. 能指定总文件夹并递归扫描全张图片；
2. 能扁平化看到全张图片，无需逐层进入；
3. 每条显示相对路径，可按路径关键词筛选；
4. 列表滚动流畅（扩展名占位即可，**不要求缩略图**）；
5. 可按路径/日期/时长/大小/分辨率/格式/标记状态筛选；
6. 标签/颜色/星级/备注重启后保留；
7. 滑动模式上下切换流畅；
8. 双击标记后列表同步；
9. 硬解失败可软解或外张打开，不闪退；
10. 预加载场景内存目标 ≤ 500MB；
11. 多选一键剪切到目标文件夹并脱离原层级；
12. 剪切成功：源删、目标可播、标记保留；
13. 剪切失败可重试且不删源；
14. 常见格式 MP4/MKV/AVI/MOV/TS/WebM 可覆盖；
15. 不支持格式有明确提示，不闪退。

## 13. 风险与对策

| 风险 | 对策 |
|------|------|
| 存储权限限制 | SAF + MediaStore 优先；全盘权限仅作备选 |
| 跨卷剪切慢 | 进度 + 后台任务 + 失败重试 |
| 老格式无法硬解 | LibVLC/FFmpeg 软解 + 外张打开 |
| 软解发热耗电 | 提示、限制并发、硬解优先 |
| 误删 | 二次确认、失败不删源；二期回收站 |
| 商店政策 | 少用 MANAGE_EXTERNAL_STORAGE |
| 缩略图占空间 | 缓存上限 + 清理 |
| 深路径过长 | 省略显示 + 完整查看 |
| 海量扫描耗时 | 后台、增量、进度、可取消 |
| 滑动卡顿 | 预加载 + 实例回收 |
| 预加载内存高 | 限制 N，大文件浅缓冲 |
