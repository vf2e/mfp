# 过片（Guopian）交互原型说明 V1.0

| 项目 | 内容 |
|------|------|
| 产品 | 过片 Guopian |
| 日期 | 2026-09-28 |
| 状态 | 可出高保真 / 可开发对照 |
| 关联 | 需求 V1.0、技术选型 V1.0、开发任务清单 V1.0 |
| 默认决策 | 上下滑切换；双击=保留；支持横屏锁定；中文 |

---

## 0. 设计约束（给 UI）

1. **工具产品**：信息密度高于娱乐 App，但滑动页必须「沉浸可藏 UI」。
2. **主色**：深青灰背景 + 亮橙强调（标记/主按钮）；深色模式为默认推荐。
3. **第一屏品牌**：启动页产品名「过片」为最大字号，副标题一行即可。
4. **列表页不是仪表盘**：不要堆统计卡片；根路径 + 搜索/筛选 + 视频流即可。
5. **滑动页零卡片**：标记用底栏按钮，不用浮层贴纸打扰画面。

---

## 1. 信息架构

```
启动 / 权限 / 选根目录
        ↓
主壳（BottomBar）
├─ 视频库（默认 Tab）
├─ 分类（智能分类）
├─ 标签
├─ 任务
└─ 设置
        ↓（从视频库点击条目）
滑动浏览（全屏，无 BottomBar）
```

---

## 2. 全局交互约定

| 操作 | 行为 |
|------|------|
| 系统返回 | 滑动页→回视频库（保留滚动位置）；其余按栈 |
| 主操作色 | 亮橙：剪切到、扫描、主要 CTA |
| 危险操作 | 删除、覆盖：红色 + 二次确认对话框 |
| 空态 | 插画/简图标 + 一行说明 + 一个 CTA |
| Toast/Snackbar | 标记成功可 Undo；剪切开始用通知+任务页 |

---

## 3. 逐屏说明

### S00 启动页 Splash

**目的：** 品牌识别 + 初始化（读根目录偏好）。

**结构：**

- 居中：Logo + 标题「过片」
- 下：副标题「本地视频，滑动过一遍就整理好」
- 无广告、无运营位

**逻辑：** 有根目录且权限有效 → S10；否则 → S01/S02。

---

### S01 权限说明页

**目的：** 解释为何要视频访问权限（若走 MediaStore 补读）及后续选文件夹。

**文案要点：**

- 全部本地处理，不上传视频
- 需要你选择「总文件夹」后才能扫描

**CTA：** 继续 → 系统权限对话框 → S02。

---

### S02 选择总文件夹（Onboarding）

**目的：** SAF 选树根。

**结构：**

- 标题：选择视频总文件夹
- 说明：将递归扫描其中所有子文件夹里的视频，扁平展示
- 主按钮：选择文件夹
- 次要：查看示例路径说明（折叠）

**选中返回后：** 展示可读路径预览 +「开始扫描」→ 进入 S10 并出扫描进度。

---

### S10 视频库（主界面）

**目的：** 扁平浏览全部/筛选结果；进入滑动；多选剪切。

#### 顶区（自上而下）

1. **标题行：** 「过片」或「视频库」+ 右侧搜索图标  
2. **根路径条：** `📁 /MyVideos`（可点）→ 更换根目录  
3. **工具行：** 筛选 | 排序 | 视图（网格/列表）| 更多  

#### 快捷芯片（横滑，可换行省略）

- 全部 | 未整理 | 保留 | 待删除 | 已剪切  

#### 中部内容

**网格模式（默认）：**

- 2–3 列（随宽度）
- 单元格：缩略图、左下时长、右上标记色点/星、下方相对路径两行省略  

**列表模式：**

- 左缩略图，右：文件名 / 相对路径 / 大小·时长·格式 / 标记  

#### 交互

| 手势 | 结果 |
|------|------|
| 单击条目 | 进入 S20 滑动浏览（当前筛选+排序为播放列表） |
| 长按条目 | 进入多选，该项选中 |
| 下拉 | 触发增量扫描（有进度） |

#### 扫描中

- 顶下线性进度：已发现 xxx 个视频  
- 列表可先展示已入库部分（若实现流式）；否则空态+进度  

#### 多选模式底栏

- 已选 N  
- 按钮：标记 | 剪切到 | 删除 | 分享 | 取消  

**空态：** 「还没有视频」+ 去选择文件夹 / 重新扫描。

---

### S11 筛选面板（从 S10 打开）

**形态：** 底部 Sheet 或侧滑面板（手机用底部 Sheet 全高 90%）。

**区块顺序：**

1. 路径包含（输入框，支持空格分多词 AND/OR 说明写微弱提示：默认包含）  
2. 路径排除  
3. 子文件夹（下拉多选，数据来自索引聚合）  
4. 日期范围、时长、大小  
5. 格式（扩展名 chips）  
6. 标记状态、星级、颜色  
7. 底部：重置 | 保存为智能分类 | 查看结果  

**保存智能分类：** 弹窗输入名称 → 写入「分类」Tab。

---

### S12 排序菜单

菜单项：修改日期、名称、大小、时长、分辨率、路径、随机；每项可切换升/降（随机除外）。

随机：进入滑动前固定本会话 seed（用户无感）。

---

### S13 路径详情轻弹层

从条目路径或滑动页路径点击：

- 完整相对路径  
- 完整 URI/绝对路径（可折叠）  
- 复制路径  

---

### S20 滑动浏览（核心屏）

**目的：** 像刷短视频一样过片并标记。

#### 布局层级（从底到顶）

```
[视频画面 Layer]
[手势接收 Layer]
[顶部信息条]     ↑ 可隐藏
[底部播放控制]   ↑ 可隐藏
[底部标记栏]     ↑ 可隐藏
[退出/更多]
```

#### 顶部信息条

- 左：返回  
- 中：文件名（单行省略）  
- 下：相对路径（更小字）+ `12 / 5023`  
- 右：隐藏 UI 开关 / 更多（横竖屏锁定等）  

#### 底部播放控制

- 进度条 + 当前/总时长  
- 一行图标：倍速 | 静音 | 字幕 | 音轨 | 画面比例 | 旋转  

#### 底部标记栏（固定高亮区）

单行可横滑按钮组：

`未整理 | 保留 | 待定 | 待删除` → `标签` `星级` `颜色` `备注` `剪切到` `删除` `分享`

当前状态按钮填充主色。

#### 手势（默认）

| 手势 | 行为 | 反馈 |
|------|------|------|
| 上滑 | 下一个 | 页跟随 |
| 下滑 | 上一个 | 页跟随 |
| 单击画面 | 播/停；并切换控制栏显隐 | |
| 双击 | 标记「保留」 | 短暂「已保留」+ 可选 Undo Snackbar |
| 长按 | 2x，松开恢复 | 顶角显示 2.0x |
| 左右拖 | 快退/快进 | 显示目标时间 |

#### 边缘情况

- 第一条再下滑：轻微回弹 + Toast「已是第一部」  
- 最后一条且播完策略=停止：停在结尾  
- 播完策略=自动下一个：无缝上滑同效  
- 加载失败：画面中央文案 +「尝试兼容播放」「用其他应用打开」  

#### 横屏

- 信息条/标记栏仍贴边；标记栏可改为侧向窄条（若时间紧，V1.0 横屏仍用底栏，允许占高）。  
- 设置可锁竖/锁横/自动。

#### 退出

- 返回：回 S10，列表定位到当前项（尽量）。  
- 标记已持久化。

---

### S21 滑动页 · 标签/星级/颜色/备注

- **标签：** 小 Sheet，已有标签多选 + 新建  
- **星级：** 1–5 星横向  
- **颜色：** 五色圆点  
- **备注：** 单行/多行输入，确定保存  

均不默认自动下一首。

---

### S22 剪切到（通用，S10 多选或 S20 单条）

**步骤：**

1. 标题：剪切到…（说明：文件将移动到目标文件夹）  
2. 最近目标（横滑卡片）  
3. 预设列表  
4. 选择其他文件夹 / 新建子文件夹  
5. 冲突策略：自动重命名（默认）| 跳过 | 覆盖  
6. 主按钮：开始剪切（显示将处理 N 个）  

**确认框（覆盖时加重）：** 不可撤销提示（V1.0 无回收站）。

开始后：Snackbar「正在剪切，可在任务中查看」→ 可跳 S40。

---

### S30 分类 Tab

- 列表：系统快捷（未整理、保留…）+ 我的智能分类  
- 左滑删除自定义分类  
- 点击 → 应用 Filter 并跳转 S10（或本页嵌入结果，V1.0 建议跳 S10 并带芯片）  

---

### S31 标签 Tab

- 标签列表（名+色+引用数）  
- 增删改  
- 点击标签 → S10 筛选含该标签  

---

### S40 任务 Tab

**进行中：**

- 类型图标、标题「剪切到 xxx」、进度条、当前文件名、取消  

**历史：**

- 成功/失败/取消状态、时间、失败可点进看条目重试  

**空态：** 还没有任务。

---

### S50 设置

分组：

1. **视频库：** 当前根目录、更换、立即扫描、自动扫描开关  
2. **滑动浏览：** 预加载 1/2/3、双击动作、滑动方向对调、播完行为、标记后自动下一个  
3. **播放器：** 硬解优先 / 软解优先 / 外部播放器  
4. **存储：** 缩略图缓存大小、清理缓存、清理任务记录  
5. **默认：** 默认排序、默认目标文件夹、默认冲突策略  
6. **隐私：** 本地处理说明  
7. **关于：** 过片 Guopian · 版本 · 开源许可（VLC 等）  

---

### S51 更换根目录确认

- 警告：将重新扫描；V1.0 不保留旧根下索引标记  
- 确认 / 取消

### S60 对话框汇总

| ID | 场景 | 要点 |
|----|------|------|
| D1 | 删除视频 | 可恢复性说明（跟系统） |
| D2 | 覆盖冲突 | 高危 |

| D5 | 权限丢失 | 重新选择文件夹 |

## 4. 关键路径线框（文字线框）

### 4.1 首次使用

```
S00 → S01 → S02 选夹 → 扫描进度挂在 S10 → 网格出现视频
```

### 4.2 过片标记剪切

```
S10 点「未整理」→ 点某视频 → S20 上滑过片
 → 双击保留 / 点待删除 → 返回 S10
 → 芯片「保留」→ 多选全选 → S22 剪切到 → S40 看进度
```

### 4.3 路径筛选过片

```
S10 → S11 路径包含「2024/旅行」→ 查看结果
 → 点进 S20 → 边看边标
```

## 6. 动效规范（至少 2–3 个有意动效）

1. **滑动页切换：** 垂直跟手 + 短距离 settle（系统 Pager 默认即可，忌花哨缩放）。  
2. **双击标记：** 状态按钮色填充 150–200ms + 轻触反馈。  
3. **多选进入：** 底栏自底滑入；条目勾选缩放轻弹。  
4. （可选）扫描完成：进度条收起 + 轻提示「共 x 部视频」。

禁止：全屏粒子、无意义光晕、营销贴片动效。

## 7. 无障碍与可用性

- 滑动页关键按钮 `contentDescription`：保留、待删除、下一个等  
- 字体随系统缩放时，标记栏可横滑不挤爆  
- 触控热区 ≥ 48dp
