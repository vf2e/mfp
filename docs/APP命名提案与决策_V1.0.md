## 1. 命名原则

1. **一眼懂场景**：本地、大量视频、快速过一遍、整理归档；
2. **短、好念、好搜**：中文 2 字优先，避免生僻字；
3. **和「刷短视频」动作同构**，但要像「工具」而非「娱乐社区」；
4. **包名/商标风险可控**：不蹭大厂品牌（抖、快、B 站等）；
5. **可延伸**：后续可出「过片 Pro / 过片桌面」而不别扭。

## 3. 选定结论

### 正式名称

| 项 | 决定 |
|----|------|
| **中文名** | **过片** |
| **英文/拼音名** | **Guopian** |
| **一句话副标题** | 本地视频，滑动过一遍就整理好 |
| **应用商店短描述** | 深层级视频库扁平浏览，像刷短视频一样过片、标记，一键剪切归档 |
| **建议包名** | `com.guopian.app` |
| **ApplicationId** | `com.guopian.app` |
| **深链 scheme（预留）** | `guopian://` |

### 选定理由

1. 产品北极星就是「**过**一遍片子再归档」，名与核心交互同构；
2. 两字好记、图标好做（可用「过」字或胶片+箭头）；
3. 和娱乐短视频产品区隔：副标题强调「本地 / 整理 / 剪切」；
4. 拼音 **Guopian** 可作国际标识与域名占位（如 guopian.app）。

### 歧义处理（产品侧）

- 启动页/商店首句固定带「**本地视频整理**」；
- 不做社交、推荐流、账号体系，避免被理解成「看片 App」；
- 图标偏工具风（文件夹/胶片/对勾），避免娱乐风大色块。

## 4. 品牌元素建议（给设计）

| 元素 | 建议 |
|------|------|
| 主色 | 深青灰 + 一抹亮橙（工具感 + 操作高亮），**避开**纯紫渐变与默认 AI 风 |
| 图标 | 简写「过」或竖向胶片帧 + 上滑箭头 |
| 启动句 | 过片 · 本地视频快速整理 |
| 通知标题 | 过片：正在扫描 / 正在剪切 |
