## 0. 测试环境

### 0.1 设备矩阵（最低）

| 代号 | 条件 | 用途 |
|------|------|------|
| D-MID | Android 13/14，8GB，中端 SoC | 主回归 |
| D-LOW | Android 10/11，4–6GB | 内存与降级 |
| D-NEW | Android 15 | 权限与行为 |
| D-SD | 带可插拔 SD（或模拟跨卷） | 跨卷剪切 |

### 0.2 测试资产

| 资产 | 要求 |
|------|------|
| LIB-5K | ≥5000 视频，目录深度 ≥10，含中文路径 |
| LIB-DEEP | 单路径深度 ≥20 |
| FMT-CORE | MP4/H.264、MP4/HEVC、MKV、MOV、WebM、TS、AVI 各 ≥3 |
| FMT-LEGACY | RMVB、WMV、FLV、VOB 各 ≥1（尽力） |
| FMT-SUB | 外挂 SRT/ASS + MKV 内封字幕 |
| BIG-1 | 单文件 ≥2GB |
| EDGE-0 | 0 字节/损坏文件头各 1 |

资产不进 Git；路径写入测试机本地配置。

### 0.3 用例编号规则

`模块-序号`，如 `SCAN-01`。结果：通过 / 失败 / 阻塞 / 不适用。

## 12. 缺陷严重级别

| 级别 | 定义 | 发版 |
